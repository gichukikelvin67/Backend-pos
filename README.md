H1 PROJECT NAME

M-Pesa POS

H1 Authors

Kelvin Kariuki

H1 Description

A RESTful backend for a Business Point of Sale (POS) system built with Node.js, Express, MongoDB, and Safaricom Daraja API.

The backend handles product management, order management, authentication, and M-Pesa payment integration. It is designed to work together with the Next.js frontend of the M-Pesa Business POS application.

H2 TechStack

Node.js – JavaScript runtime


Express.js – Backend web framework


MongoDB – Database


Mongoose – MongoDB object modeling


Axios – API requests


JWT – Authentication


API – M-Pesa payments
Render – Backend deployment
